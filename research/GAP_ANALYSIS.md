# HFT priority gap analysis

Repository baseline: current checked-out HFT commit, preserved in experiment metadata. Local branch: research/hft-evidence-revision.

1. **P0 — Evidence scope:** the supplied paper calls testing “formal verification,” assumes an HJB-optimal imbalance strategy, and claims LOBSTER/ITCH real-tape adapters, pinned physical arenas and cache guarantees that the repository does not establish. Replace with actual executable architecture, synthetic queue-aware simulations, differential tests and measured host latency. Existing repository documentation is substantially more cautious than the supplied paper.
2. **P0 — Live-tool test defect:** stdin is closed then `communicate()` attempts to flush it under Python 3.12 and 3.13, so the official local CI script fails. Detach the closed stdin handle without weakening checks; rerun the complete suite and drills.
3. **P1 — Quantile definition:** fixed histogram quantile currently floors q*n; odd sample sizes can select below the nearest-rank quantile. Correct to ceil and add a regression test.
4. **P1 — Timing evidence:** JSON contains only quantiles. Export existing bounded histogram counts and units without changing the timed recording path; preserve per-run outputs, timer overhead, affinity/noise, CPU/compiler and event counts. These are binned distributions, not raw per-event traces or network latency. Treat p99.9/max and host speedups cautiously.
5. **P1 — Research statistics:** lab supports paired markets and exact sign tests but no multiplicity correction. Recompute mean-difference confidence intervals and exact sign tests from per-market JSON and apply Holm correction across prespecified comparisons. Preserve edge/inventory decomposition. Never infer empirical trading performance from this informed-flow generator.
6. **P1 — Ablation/robustness:** reproduce the documented 16-market comparison, confirm on fresh seeds, run seven generator regimes, separate three-hop delay from aggregate latency, sweep queue penalty and fees, and preserve training-only selection with held-out seeds. A reference no-alpha variant is an internal ablation, not a competitive external strategy baseline.
7. **P2 — Novelty/venues:** familiar cache-aware structures and synthetic backtests do not establish a new theory. Prior numerical manuscript claims need regenerated outputs; no old performance baseline, mutation kill rate or instruction budget is called reproduced without rerunning its specific experiment. Current literature and venue verification remain subject to blocked scholarly access.

Required gates: corrected build, all 19 CTest checks, complete Python suites and 28 drills; functional replay oracle; matched repeated latency outputs; reproducible statistics and artifact checks; generated IEEE PDF; critical reviewer/evidence report. Optional unexecuted work (long fuzz campaigns, mutation reruns, perf/callgrind gate, real exchange/tape experiments) must be explicitly identified.
